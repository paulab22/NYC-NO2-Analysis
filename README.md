## About This Project

This project analyzes nitrogen dioxide (NO₂) air pollution levels across New York City neighborhoods using NYC OpenData. The analysis focuses on comparing NO₂ concentrations between the Upper West Side and Queens Village and uses exploratory data analysis, data visualization, and a Welch two-sample t-test to determine whether the difference in average NO₂ levels is statistically significant. The project also explores the potential environmental and public health implications of differences in air pollution exposure across communities.
